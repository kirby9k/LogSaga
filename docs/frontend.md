## Routes

### `/` — Recently Played
- Data: `useRecent({ limit: 50, type? })`
- UI: type toggle (All / Movies / TV) → responsive poster grid; Load More; click → item detail

### `/continue` — Continue Watching
- Data: `useInProgress()` with `refetchInterval: 30_000`
- UI: card list — poster + title + PercentBar + "Resume at Xm"; empty state if none

### `/partial` — Started Not Finished
- Data: `useSessions({ status: 'partial', limit: 100 })`
- UI: vertical list — poster + PercentBar + "stopped at Xm of Yh Zm" + TimeAgo

### `/history` — Full History
- Data: `useSessions(params)` where params come from URL search params
- UI: filter bar (search debounced 300ms, type, status, date range) + shadcn Table + pagination
- CSV export: fetches up to 500 rows, builds CSV string, downloads via `URL.createObjectURL`

### `/shows` — TV Shows
- Data: `useShows(search)` debounced
- UI: poster grid — show poster + title + watched/total progress bar + next unwatched label
- Clicking a show → `/history?search=<show_title>`

### `/stats` — Statistics
- Data: `useStats(days)` with days toggle (30 / 90 / 365)
- UI: 4 summary cards + bar chart (Recharts via shadcn ChartContainer) + top shows table
- Chart data is gap-filled client-side: full date range generated, API data merged, missing days → 0

### `/items/$itemId` — Item Detail
- Data: `useItem(Number(itemId))`
- UI: two-col desktop (poster | info); sessions list with badges; observations in Collapsible (collapsed by default)

### `/settings` — Settings / Status
- Data: `useHealth()` with `refetchInterval: 30_000`
- UI: Status card + session rules card (read-only) + Rebuild button (`useRebuildSessions` mutation)

## API layer

### `src/api/client.ts`
```typescript
import createClient from 'openapi-fetch'
import type { paths } from './types'
export const apiClient = createClient<paths>({ baseUrl: '/' })
```

### `src/api/queries.ts` — available hooks

| Hook | Endpoint | Notes |
|------|----------|-------|
| `useHealth()` | GET /api/health | refetchInterval: 30s |
| `useRecent(params)` | GET /api/recent | staleTime: 30s |
| `useSessions(params)` | GET /api/sessions | staleTime: 30s |
| `useInProgress()` | GET /api/in-progress | refetchInterval: 30s |
| `useShows(search)` | GET /api/shows | staleTime: 30s |
| `useItem(id)` | GET /api/items/{id} | staleTime: 30s |
| `useStats(days)` | GET /api/stats | staleTime: 30s |
| `useRebuildSessions()` | POST /api/admin/rebuild-sessions | useMutation; invalidates all queries on success |

### Regenerating types

With the backend running:
```bash
npm run generate-types
# runs: openapi-typescript http://localhost:8000/api/openapi.json -o src/api/types.ts
```

Commit `src/api/types.ts` so the frontend can build without the backend running.

## Dev and build commands

```bash
# Install dependencies
npm install

# Start dev server (http://localhost:5173, /api and /art proxied to :8000)
npm run dev

# Type check
npm run build  # tsc -b is part of the build

# Production build → backend/dist/
npm run build

# Regenerate API types (backend must be running on :8000)
npm run generate-types
```

Build output goes to `../backend/dist` (configured in `vite.config.ts`).
FastAPI serves it automatically — no separate Node server in production.

## Adding a new page

1. Create `src/routes/mypage.tsx` with `export const Route = createFileRoute('/mypage')({...})`
2. TanStack Router Vite plugin auto-updates `src/routeTree.gen.ts` on next `npm run dev`
3. Add a nav link in `src/components/layout/Sidebar.tsx`
4. Add a hook in `src/api/queries.ts` if a new endpoint is needed
5. Run `npm run build` to update `backend/dist/`

## Key config files

### `vite.config.ts`
- Plugins: TanStackRouterVite, react, tailwindcss
- Alias: `@` → `./src`
- Dev proxy: `/api` and `/art` → `http://localhost:8000`
- Build output: `../backend/dist` (emptyOutDir: true)
- Uses `import.meta.dirname` not `__dirname` (Vite 8 requirement)

### `tsconfig.json` (root)
Must have `compilerOptions.paths: { "@/*": ["./src/*"] }` — required by shadcn CLI
to resolve `@/` imports when adding new components.

### `.npmrc`
`legacy-peer-deps=true` — required because `openapi-typescript` declares a peer dependency
on `typescript@^5.x` but this project uses TypeScript 7.
